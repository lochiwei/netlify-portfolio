正十邊形 String Art
包絡線圖案

以 O = (0, 0) 為圓心，三組 String Art 重現原圖右半邊的螺旋花瓣圖案

🔍幾何結構分析

仔細觀察原圖左半邊（帶有 A、B、C、D、E、F 標記），可辨認出以下結構：

圖形由一系列「線段」構成，而非曲線。具體來說是「弦藝術」（String Art）技法——用大量直線線段的包絡線（Envelope），視覺上形成類似拋物線的曲線效果。

整體架構

  • 外框：正10邊形（十邊形），以 O 為圓心、r 為半徑的外接圓上10個頂點
  • 輻射線（Spokes）：從 O 連到10個頂點的10條線段
  • 三組 String Art 包絡線：每個扇形三角形（O, Vk, Vk+1）內，在三個頂點角各做一組包絡線
  • 視覺效果：30組包絡線 × 每組 m-1 條線段，充滿整個十邊形，形成「花瓣式螺旋」圖案

三個參數均為 GeoGebra 可調滑桿，改變後所有線段自動重算更新，無任何 hard-coded 數值。

📐String Art 包絡線原理

在三角形的某頂點 V，兩邊 VA 和 VB 各取 m 等份後，以互補參數連線：

P₁(j) = V + (j/m)·(A − V)　←　VA 邊第 j/m 分點
P₂(j) = V + (j/m)·(B − V)　←　VB 邊第 j/m 分點
連線：P₁(j) ── P₂(m − j)　j = 1, 2, …, m−1

這 m−1 條線段的包絡線在視覺上形成一條與兩邊相切的拋物線弧。

三角形三個頂點的對應公式

// 頂點 O（圓心角）
P₁ = (j/m) · Vk　，　P₂ = ((m−j)/m) · Vk+1

// 頂點 Vk
P₁ = (1−j/m) · Vk　，　P₂ = (j/m)·Vk + ((m−j)/m)·Vk+1

// 頂點 Vk+1
P₁ = (1−j/m) · Vk+1　，　P₂ = (j/m)·Vk+1 + ((m−j)/m)·Vk

💻完整 GeoGebra 指令

依序在 GeoGebra 輸入欄貼入以下指令，即可重現圖形：

# ── 基礎參數 ──────────────────────────────────────
n = 10          # 正多邊形邊數
r = 5           # 外接圓半徑
m = 40          # 每邊等分數（越大越細膩）
O = (0, 0)      # 中心點（初始條件，唯一自由物件）

# ── 正十邊形頂點（極座標，從頂部順時針）──────────
Vlist = Sequence((r; 90° + k × 360° / n), k, 0, n − 1)

# ── 外框多邊形 ──────────────────────────────────
polygon_outer = Polygon(Vlist)

# ── 輻射線（spokes） ────────────────────────────
spokes = Sequence(Segment(O, Element(Vlist, k)), k, 1, n)

# ── String Art 組 1：頂點 O 角 ──────────────────
# 連接 spoke_k 上 j/m 點 → spoke_{k+1} 上 (m-j)/m 點
stringsO = Sequence(Sequence(
  Segment(
    (j/m) × Element(Vlist, k),
    ((m−j)/m) × Element(Vlist, Mod(k, n) + 1)
  ), j, 1, m−1), k, 1, n)

# ── String Art 組 2：頂點 V_k 角 ────────────────
# 在 V_k→O 與 V_k→V_{k+1} 兩邊之間
stringsVk = Sequence(Sequence(
  Segment(
    (1 − j/m) × Element(Vlist, k),
    (j/m) × Element(Vlist, k) + ((m−j)/m) × Element(Vlist, Mod(k, n) + 1)
  ), j, 1, m−1), k, 1, n)

# ── String Art 組 3：頂點 V_{k+1} 角 ────────────
# 在 V_{k+1}→O 與 V_{k+1}→V_k 兩邊之間
stringsVk1 = Sequence(Sequence(
  Segment(
    (1 − j/m) × Element(Vlist, Mod(k, n) + 1),
    (j/m) × Element(Vlist, Mod(k, n) + 1) + ((m−j)/m) × Element(Vlist, k)
  ), j, 1, m−1), k, 1, n)

🪜構建步驟

1

建立基礎參數

定義 n=10、r=5、m=40 及圓心 O=(0,0)。三個數值參數可設為滑桿，方便動態調整。

2

以極座標建立正十邊形頂點清單

用 Sequence 搭配極座標格式 (r; 90°+k×360°/n)，一次生成10個頂點的列表 Vlist。

3

建立外框多邊形與輻射線

Polygon(Vlist) 建外框；Sequence(Segment(O, Element(Vlist,k)),…) 建10條輻射線。

4

建立三組 String Art（雙重 Sequence）

外層迴圈跑10個扇形（k = 1…n），內層迴圈跑 m−1 條線段（j = 1…m−1）。利用 Mod(k,n)+1 處理最後一個扇形的循環銜接。

5

樣式設定與匯出

將所有線段設為深綠色、去除多邊形填色、隱藏格線與座標軸，最後匯出 .ggb 檔。

✨技術亮點與規範遵守

  • 全程使用 Sequence 指令：共建立 3 × (10 × 39) = 1,170 條線段，沒有任何逐一建立的物件
  • 零 hard-coded 數字：所有座標均由 GeoGebra 用極座標 (r; 角度) 在內部計算，n、r、m 三個自由參數修改後圖形即時更新
  • Mod 處理循環邊界：Mod(k, n) + 1 使第10個扇形的第二頂點正確回到 V₁，閉合多邊形
  • 唯一自由物件說明：O = (0,0) 是初始條件，必須為自由點（圓心位置是幾何圖的初始條件，無法由其他物件推導）
  • 命名規範：頂點清單 Vlist 使用大寫開頭，複合名稱使用底線，下標符合 name_{sub} 格式
